This report presents two practical Natural Language Processing mini-projects: sentiment analysis and Named Entity Recognition (NER). The sentiment analysis component uses the VADER lexicon-based approach to identify positive, negative, and neutral opinions in short social-media text. It calculates a compound sentiment score for each text and maps the score to one of three sentiment categories. Its effectiveness is evaluated using the TweetEval sentiment benchmark, with accuracy, precision, recall, macro-F1, weighted-F1, a classification report, and a confusion matrix.

The NER component uses the pretrained spaCy English pipeline to identify and classify named entities such as people, locations, organizations, products, groups, and creative works. It is evaluated against the manually annotated WNUT 2017 dataset, which contains informal user-generated text and BIO entity labels. Preprocessing preserves token order, punctuation, capitalization, and character offsets so that predicted entities can be compared with the gold annotations. Entity-level precision, recall, and micro-F1 are calculated using exact span and entity-type matching. Token-level accuracy is also reported.

The report explains the selected public datasets, data loading, preprocessing decisions, algorithmic approaches, evaluation methodology, limitations, and possible improvements. It also discusses challenges such as sarcasm, context dependence, informal spelling, rare entities, and differences between training domains. A Python implementation is included to download the benchmark datasets, run both NLP modules, and export metrics, predictions, tables, and visualizations. The two benchmarks are kept separate because they provide different gold annotations: TweetEval supplies sentiment labels, while WNUT 2017 supplies named-entity labels. This avoids creating artificial or unverified annotations. Overall, the project demonstrates how lexicon-based sentiment scoring and statistical entity recognition can be evaluated in a reproducible NLP workflow.
